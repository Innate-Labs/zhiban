## ✨ 产品简介

**知伴 — 你的 AI 恋爱顾问**

恋爱中的你，是否曾面对消息不知如何回复，吵架后不知如何破冰，或看不懂对方行为背后的真实想法？知伴，正是为此而生。

知伴是一款基于**心理学模型与情感智能**驱动的 AI 恋爱顾问 App，专为亲密关系而设计。它拥有四大核心能力：

- **话术指导** — 提供稳妥、推进、大胆三种回复思路
- **冲突解决** — 深度分析矛盾根源并给出分步和好方案
- **心理分析** — 站在对方角度解读其真实动机
- **情感倾诉** — 支持文字与语音，随时陪你聊

更独特的是，知伴配备"**记忆飞轮**"机制——每次对话都会自动积累你们的相处模式、说话风格与近期状态，越用越懂你。同时支持截图识别、纪念日智能提醒与一键隐私删除，兼顾实用与安全。

免费用户每日享有 5 次对话，Pro 会员仅需 ¥19.9/月即可解锁无限畅聊。让知伴成为你最贴心的情感伙伴，**懂爱，从了解开始**。
